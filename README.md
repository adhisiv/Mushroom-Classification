# Mushroom Classification using Machine Learning

## Project Overview
This project classifies mushrooms into edible and poisonous categories using Machine Learning algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
1. Decision Tree Classifier
2. Random Forest Classifier

## Project Workflow
1. Dataset Collection
2. Exploratory Data Analysis
3. Data Preprocessing
4. Model Training
5. Model Evaluation
6. Prediction

## Dataset
UCI Mushroom Dataset

## Objective
To classify mushrooms based on their physical characteristics and evaluate the models, with special attention to detecting poisonous mushrooms.
